# 가계부 (Budget-Log)

부부 두 iPhone에서 같이 쓰는 가계부 웹앱 (홈 화면에 추가하는 PWA).
주소: https://jaybaek-git.github.io/Budget-Log/

## 기능 (v1.0)
- **빠른 입력**: 카테고리 버튼 → 숫자패드(＋1천·＋5천·＋1만…) → 저장. 메모는 자주 쓴 메모가 버튼으로 나옴. 오늘/어제/그제/날짜 선택
- **이번 달 요약**: 지출·수입·수입−지출, 예산 막대(오늘까지 진행선), 남은 예산·하루 사용 가능액
- **내역 / 통계 / 달력**: 날짜별 내역, 카테고리별 비율·카테고리 예산, 일별 막대, 최근 6개월, 기록한 사람별 / 날짜 칸을 누르면 그날 내역·추가
- **월 예산**: 전체 + 카테고리별
- **고정지출·수입 자동 기록**: 매달 n일(말일 가능) 서버가 자동 기록 (매일 00:05)
- **알림 (웹 푸시)**: 배우자 기록 알림(내 기록은 내 폰 제외), 예산 80%·100% 알림, 고정지출 자동 기록 알림
- CSV 내보내기, 다크/라이트, 화면 좌우 스와이프로 달 이동

## 처음 설정
1. Safari에서 주소 열기 → 공유 → **홈 화면에 추가**
2. 홈 화면 아이콘으로 열기 → 설정 → **📋 연결 코드 붙여넣기** (`BUDGETLOG|URL|KEY|가족코드`) → 내 이름(예: 남편/아내) → **저장 & 연결**
3. 설정 → 알림 → **이 폰 알림 켜기** → 테스트
4. 배우자 폰: 설정 → 연결의 **배우자 폰 연결 코드 복사**로 보낸 코드를 붙여넣고 이름만 다르게

## 서버 (Supabase)
- `supabase_setup.sql` 한 번 실행 (가족 코드·`<PROJECT_ID>` 바꾸기), VAPID 키 입력, Edge Function `push`(`edge_function_push.ts`, JWT 검증 끔) 배포
- 가족 코드·키는 저장소에 올리지 않음
